## モデル上の扱い（主なもの）
- 毎晩（終電後）に初期配置へ戻す。初期配置には駅西口ポートの台数も含む（夕方の駅→自宅の利用に備える）。
- 満車で返却できない場合は「返却失敗」。車両は区画外に一時駐車し、次の作業（9:30／15:30／夜）で回収するまで貸し出せない。
- 希望車種が無いとき：(i) 利用しない／(ii) もう一方の車種に乗る（代替乗車率を記録）。往復利用の帰りは往路と同じ車種を希望する。
- 最小台数は「平日・晴れの1日」を最大60日分シミュレーションして、貸出失敗率が目標以下になる最小の自転車＋キックボード台数を探索（目標との大小がはっきりした組み合わせは途中で打ち切る）。
- 1か月・1年は平日・休日（土日祝）を含み、日ごとの気象は月の平年出現日数から抽選。電池の状態は日をまたいで引き継ぐ。年間費用は12か月の計算から。
- 電池交換の作業費は1回10分の人件費として計上（電気代は車両維持費に含む）。
- リバランス b の「駅に残す台数」はご指示どおり「夕方の駅→自宅の期待需要＋1台」。偶然の増減に対して余裕が小さく、
  夕方に駅で不足しやすい。`rebalance.station_buffer_q`（例 0.95＝ポアソン分布の95%点）で変更できる
  （比較結果：data/output/study/rebalance_buffer_test.csv）。

## 確認の手順（この作業環境から官公庁サイトに接続できないもの）
- 気象：気象庁「過去の気象データ検索」→ 埼玉県 → 久喜（アメダス、観測所番号43126）または熊谷 → 平年値（月ごとの値）。
  日降水量1mm以上・10mm以上の日数、最高気温35℃以上の日数、最低気温0℃未満の日数、最大風速10m/s以上の日数を `config.yaml` の `climate` に入れる。
  久喜アメダスで観測していない要素は熊谷の値を使う。
- 需要：東京都「協議会資料」（katsuyo_kyogikai_r05-02-02）の転換率・利用意向を画面「設定」の需要シナリオへ。
