# 気になるワード バルーン表示

会場の参加者がスマホから「気になるワード」を回答すると、会場スクリーンにバルーンで表示されるアプリです。

- ワード1つにつき円（バルーン）が1つ。ワードと回答数は円の中に表示されます。
- 円の面積は回答数に比例し、同じワードの回答が増えるほど円が大きくなるので、どのワードが注目されているかが一目でわかります。
  回答が増えた円は一瞬黄色く光ります。
- 右側に回答数・上位10ワードのランキング・回答用URL（とQRコード）を表示します。
- 全角/半角・大文字/小文字・空白の違いは同じワードとして数えます（例：「ＡＩ」「ai」）。

## 起動

Python 3.10 以上があれば、追加のインストールは不要です（標準ライブラリのみ）。

```bash
python word_balloon/server.py            # ポート 8000 で起動
python word_balloon/server.py --port 8080
```

起動すると次のように表示されます。

```
  回答ページ（参加者）: http://192.168.x.x:8000/
  スクリーン表示     : http://192.168.x.x:8000/screen
  管理ページ         : http://192.168.x.x:8000/admin   管理キー: xxxxxxxx
```

1. 会場のプロジェクターにつないだ PC のブラウザで **スクリーン表示** を開く（`F` キーで全画面、`S` キーで右パネルの表示切替）。
2. 参加者は同じ Wi-Fi につないだスマホで **回答ページ** を開く（スクリーン右下の QR コードから）。
3. **管理ページ** を開いたままにしておき、「承認待ち」に出たワードを確認して「表示する」か「非表示にする」を押します。
   イベントの前に「すべてリセット」で練習分を消してください。

## コンプライアンス対策（管理者の許可制）

| 仕組み | 動き |
|---|---|
| 要確認ワード `word_balloon/review_words.txt` | ここに書いた言葉を含む回答は **承認待ち** になり、管理ページで「表示する」を押すまでスクリーンに出ません。回答者には通常どおり「送信しました」と表示されます |
| すべて許可制 `--review-all` | 起動時に付けると、新しいワードはすべて承認待ちになります（同じワードの2件目以降は、許可済みならそのまま表示） |
| 非表示にする | 表示中・承認待ちのワードをスクリーンから消します。同じワードがまた回答されても表示されません（後から「表示する」で戻せます） |
| NG ワード `word_balloon/ng_words.txt` | 受付自体を拒否します（回答者に「受け付けられません」と表示） |

承認待ちの間に集まった回答も数えているので、許可した時点でそれまでの回答数の大きさで表示されます。
管理ページは3秒ごとに更新され、承認待ちがあるとブラウザのタブに件数が出ます。
`review_words.txt` には例として一般的な要注意語を入れてあります。会場や会社の方針に合わせて編集してください（部分一致のため、例えば「死」は「必死」も承認待ちにします）。

## 設定

| 項目 | 方法 |
|---|---|
| 回答の保存先 | `--data`（既定 `word_balloon/data/answers.json`。再起動しても回答は残る） |
| NG ワード | `word_balloon/ng_words.txt` に1行1語（部分一致で受付拒否） |
| 要確認ワード | `word_balloon/review_words.txt` に1行1語（部分一致で承認待ち）。`--review` で別ファイル、`--review-all` で全ワード許可制 |
| 管理キー | 環境変数 `WORD_BALLOON_ADMIN_KEY`（未設定なら起動ごとにランダム） |
| 案内 URL | `--public-url`（クラウド等で公開し、IP 以外の URL を案内する場合） |
| 1ワードの最大文字数 | 20文字（`store.py` の `MAX_LEN`） |
| 円の大きさ | 表示エリアに対する円の面積の目安 `FILL`、最小半径 `MIN_R`（`static/screen.html`） |

QR コードの表示にはインターネット接続（cdnjs）が必要です。接続がない場合は URL の文字だけが表示されます。

## 注意

- 参加者のスマホから PC に接続できるよう、PC のファイアウォールでポートを許可してください。
  会場 Wi-Fi で端末同士の通信が遮断されている場合は、ポケット Wi-Fi などを用意するか、`--public-url` で公開サーバーに置いてください。
- テスト：`python -m pytest tests/test_word_balloon.py`
